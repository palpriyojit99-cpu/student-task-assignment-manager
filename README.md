# Student Task & Assignment Manager

A full-stack web application designed to help students manage their academic tasks and assignments in one place.

## Project Overview

Students often have several assignments, projects, tests and other academic activities to remember. This project aims to provide a simple system where students can add, view, update and delete their tasks.

The application is being developed as part of my Junior Full Stack Developer internship.

## Main Features

- Student registration and login
- Student dashboard
- Add new tasks and assignments
- View task details
- Edit existing tasks
- Delete tasks
- Set task due dates
- Track task status
- Search and filter tasks

## Planned Technology

### Backend
- Node.js

### Database
- MySQL

### Development
- GitHub for source code and version control

## Basic Working Flow

1. Student opens the application.
2. Student registers or logs in.
3. The frontend sends the request to the backend.
4. The backend processes the request.
5. The database stores or retrieves the required information.
6. The backend sends the result back to the frontend.
7. The student sees the updated information on the screen.
